# Instrucciones finales de entrega

## Archivo principal

Entregar `Entrega_Actividad_8_Borys_Alexy_Panezo_Guerrero.pdf`.

El informe contiene los datos del estudiante, descripción técnica, diseño de la base
de datos, código del controlador, pruebas de los cinco endpoints, conclusiones,
bibliografía y enlaces al repositorio y ramas de GitHub.

## Enlaces publicados

- Repositorio: https://github.com/JBorys687/helpdesk-datacenter
- Rama integrada: https://github.com/JBorys687/helpdesk-datacenter/tree/develop
- Rama de actividad: https://github.com/JBorys687/helpdesk-datacenter/tree/feature/backend-api
- Carpeta de Drive: https://drive.google.com/drive/folders/1Ymn-EO8LBrUPv6qqT2ASUzFPNta5Pf9b?usp=sharing

## Pasos que debe realizar el estudiante

1. Abrir el PDF y revisar nombres, docente, paralelo y período académico.
2. Confirmar desde una ventana privada que la carpeta de Drive permita visualizar
   todos los archivos sin iniciar sesión.
3. Entregar el PDF en el aula virtual y verificar que se pueda descargar después de
   subirlo.

## Seguridad

No publicar archivos `.env`, contraseñas, tokens ni credenciales de PostgreSQL. La
colección Postman incluida deja el campo de contraseña vacío deliberadamente.
